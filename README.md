# Dual Memory Game

A fun and interactive memory game designed especially for children to practice attention and visual retention. This firmware is developed for a PICO 2 microcontroller and runs two completely different memory games in parallel.

## What's it about?

The project is a desktop "console" containing two simultaneous challenges for young children:
* **The Lights Game:** A visual game where the system generates a random sequence of colors (Red, Blue, Green, and Yellow) that the child must memorize and repeat using physical buttons.

* **The Letters and Numbers Game:** A cognitive challenge where an LCD screen displays sequences of symbols and characters that the player must replicate using a matrix keypad.

Both games start at level 1, and as the player correctly matches the sequence, the difficulty increases by adding a new element until reaching level 10. The game can be reset upon winning or losing.


## Technical Qualities of the Project

Despite its child-friendly appearance, the project implements fundamental and robust embedded systems programming concepts:

* **Multicore Processing (Dual Core):** The system takes full advantage of the board's hardware using the `pico_multicore` library. The LED game runs continuously on Core 0, while the word game and keyboard run on Core 1. This ensures that the waiting and routines of one game do not freeze the other.

* **Finite State Machines (FSM):** All game logic and peripheral readings are modeled using state machines (`INIT`, `GENERATE`, `PLAY`, `ANSWER`, `COMPARE`, `WAIT_FOR_RESET`). This avoids the use of blocking code and allows for smooth responsiveness.

* **Peripheral Integration and Control:**

    * Management of an LCD screen via the data bus using the `hardware_i2c` library.

    * Dynamic scanning of a 4x4 matrix keypad by sweeping rows and columns.

    * Software-enabled internal *Pull-Up* topology configuration for physical buttons (`gpio_pull_up`), preventing erroneous readings due to electrical noise (floating pins).

* **Event Buffers:** The system uses a custom C memory structure (`buffer.c`) to securely and systematically record events generated by the microcontroller and logically compare them against user inputs.

* **Hardware Randomization:** It uses the `pico_rand` API and the microcontroller hardware (`get_rand_32()`) to guarantee unpredictable and unique sequences in each game.
